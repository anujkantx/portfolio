## 🚀 Featured Engineering Projects

### 1. [AirDose](https://github.com/anujkant-iitm/airdose) — Personal Air Pollution Exposure Intelligence
> *Location-aware personal air pollution exposure intelligence & environmental health tracking system.*

- **Problem**: Generalized city-wide AQI averages fail to capture hyper-local exposure spikes (congested transit corridors, industrial zones) or quantify the physiological cumulative pollutant dose inhaled by commuters.
- **Solution & Architecture**:
  - Engineered an asynchronous **FastAPI** backend to ingest multi-point GPS waypoints and compute cumulative inhalation doses for PM2.5, PM10, and NO2 in near real-time.
  - Implemented a spatial geohash-based **Redis** cache with a sliding 15-minute TTL to overcome third-party atmospheric API rate limits.
  - Built an interactive **Next.js + Tailwind** telemetry dashboard rendering exposure curves and dynamic low-pollution route recommendations.
- **Tech Stack**: `Next.js` • `TypeScript` • `FastAPI` • `Python` • `PostgreSQL` • `Redis` • `OpenAQ APIs` • `AWS EC2` • `Docker`

### 2. [Studyit](https://github.com/anujkant-iitm/studyit) — Academic Intelligence & Curriculum SaaS
> *Unified academic ecosystem replacing fragmented cloud drives with indexed, verified course resources.*

- **Problem**: University engineering students waste hours navigating dead Google Drive links and unorganized chat forwards to locate past exam papers, notes, and syllabus materials.
- **Solution & Architecture**:
  - Designed an ontological relational database hierarchy (`Degree → Department → Semester → Subject → Unit`) in **PostgreSQL** with foreign key integrity.
  - Implemented **Google OAuth 2.0** authentication with rotating JWT sessions and role-based access controls for resource submission and peer reviews.
  - Built with **Next.js App Router** and React Server Components for instant search filtering and fast PDF asset streaming.
- **Tech Stack**: `Next.js 16` • `React 19` • `TypeScript` • `FastAPI` • `PostgreSQL` • `SQLAlchemy` • `Tailwind CSS` • `Google OAuth`

## 💻 About This Portfolio Repository

This repository contains the source code for my editorial portfolio website, engineered with:
- **Framework**: [Next.js 16 (Turbopack)](https://nextjs.org) + [React 19](https://react.dev)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) with custom dark editorial tokens
- **Typography**: [Geist Sans & Mono](https://vercel.com/font), Newsreader Serif, Bebas Neue
- **Motion**: [Motion (Framer Motion v12)](https://motion.dev) with accessibility-first prefers-reduced-motion support

### Quickstart

```bash
# Clone the repository
git clone https://github.com/anujkantx/portfolio.git
cd portfolio/portfolio

# Install dependencies
npm install

# Run the local development server
npm run dev

# Production build & static generation
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the live build.
